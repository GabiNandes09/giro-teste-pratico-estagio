
Este é um teste prático utilizando Java para criação de uma API,
Foi utilizado um Bando MySQL em localhost

Para execução do sistema:
1º - Criar um database com o nome "giroTech", exatamente como está no application.properties
2º - Dentro de application.properties alterar username e password de acordo com o necessário para conexão.
3º - Inicializar a classe GiroTechApplication.
4º - utilize a url base "http://localhost:8080/api/v1/"
